# Lesson 05 — Role prompts

## Concept
A useful role defines responsibility, evidence boundaries, and behavior rather than a theatrical persona.

## Why it works
The role keeps extraction grounded in the supplied source and makes non-inference a standing rule.

## When to use it
Use a role when the same operating boundary applies across the whole task.

## When not to use it
“You are a helpful assistant” adds little when the actual responsibility is unspecified.

## Common failure modes
The model may infer a role or location from context instead of leaving it empty.

## Exercise
Return three literal-tab fields: name, role, and area.

## What to observe
Compare a generic helper role with a grounded extraction-system role.
