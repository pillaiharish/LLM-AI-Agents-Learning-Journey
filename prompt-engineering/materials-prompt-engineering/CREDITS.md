# Credits and inspiration

The original seed materials for this project used concepts and sample code associated with Real Python's [“Practical Prompt Engineering”](https://realpython.com/practical-prompt-engineering/) tutorial.

The active curriculum has been rewritten with original exercises for local Ollama, exact-match testing, structured formats, instruction boundaries, public-meeting extraction, and holdout evaluation. It does not reproduce the tutorial or its prose.

The optional public-transcript extension can download material from [BetaNYC's hearings-transcripts repository](https://github.com/BetaNYC/hearings-transcripts). That dataset is described by its maintainers as CC BY 4.0. Downloaded files remain outside the committed curriculum and require their own attribution and privacy review.
